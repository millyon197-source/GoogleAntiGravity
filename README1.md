This repository includes an implementation of a Node.js, Three.js browser based project that will read the construction plan .xml and present the structures contained within. .dae components are located and displayed.

## Prerequisites

1. **Python 3**: Make sure Python 3.x is installed and in your environment path.
2. **Loose Assets**: You must have unpacked the game assets into a loose folder (e.g. using `XRCatTool` or Steam Tools) retaining the `assets/` subfolder structure.

## Usage

Once the required packages are installed and verified, from the project directory run "npm run build" followed by "npm run dev"

The codebase when running will load a browser path of "localhost:300[0-4]".
